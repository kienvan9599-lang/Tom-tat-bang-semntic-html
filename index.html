Internet là gì?

Internet là mạng lưới toàn cầu kết nối hàng tỷ thiết bị qua giao thức TCP/IP.

  • Kết nối máy tính trên toàn thế giới
  • Hỗ trợ email, chat, truyền file, video call
  • Là hạ tầng cho World Wide Web hoạt động

World Wide Web (WWW)

Web là hệ thống tài liệu siêu văn bản chạy trên Internet, truy cập qua trình duyệt.

  • Phát minh bởi Tim Berners-Lee năm 1989
  • Sử dụng giao thức HTTP/HTTPS
  • Gồm hàng tỷ trang web liên kết nhau

HTML & CSS

HTML tạo cấu trúc, CSS tạo giao diện cho trang web.

  • HTML dùng thẻ semantic: header, main, section, footer
  • CSS kiểm soát màu sắc, font, bố cục
  • Kết hợp JavaScript để tạo tương tác
