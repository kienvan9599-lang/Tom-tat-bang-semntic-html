Tổng quan Internet và Web

Internet

Hạ tầng mạng toàn cầu kết nối các thiết bị qua giao thức TCP/IP.

Web

Dịch vụ chạy trên Internet, truy cập trang web qua HTTP/HTTPS.

Web Server

Máy chủ lưu trữ và phục vụ file HTML, CSS, hình ảnh cho trình duyệt.

Browser

Phần mềm gửi yêu cầu đến server và hiển thị trang web cho người dùng.
